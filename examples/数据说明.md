# 审查来稿

records 使用现有文档批次格式。metadata.minutes 是预计人工审查分钟，不是实际标签；source_group 是演练来源组。前半组另给人工决定，后半组没有人工标签。部分文本共享内容，近重复身份应由固定去重运行得出。

context 示例经本地批次接收记录并使用审查租约保存前半组人工决定。规则 findings 与人工决定分开保存，不能把规则命中当成训练真值。


metadata.arrived_at 与 decisions.decided_at 是演练时间。context 按九月两轮来稿及翌日决定、十月新稿的顺序推进可注入时钟，实际审查历史因此保留两个先后截止，不能把十月候选或事后决定送入九月验证。

round_demo 复用同一组记录，先建立九月去重运行，再以 `cutoff=2026-09-10T00:00:00Z`、`budget_minutes=30` 规划十月一轮。轮次证据里的 `training.decisions`、`candidates`、`selection` 与 `backtest.folds` 可复算选样；演示还包含来源下限冲突、租约人工决定、换版或撤回造成的轮次失效，以及重复执行不重复入队。
